# Changelog

## 0.2.0 - 2026-06-09

- Added `--out-summary` for compact GitHub Actions summaries and PR comments.
- Added an expandable generated-policy section to the summary output so reviewers can scan the decision first and inspect the full policy when needed.
- Added CLI, renderer, README, showcase, and GitHub Actions smoke coverage for the summary workflow.
- Added project URL metadata for repository, issues, and changelog links.

## 0.1.0 - 2026-06-08

- Initial public project.
- Added MCP manifest and transcript parsing.
- Added least-privilege policy generation, validation, policy diffing, risk scoring, Markdown reports, JSON reports, and JUnit output.
- Added examples, Chinese-first README, security notes, contributing guide, tests, and GitHub Actions CI.
